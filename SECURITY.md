# Security Policy

This repository contains intentionally vulnerable teaching branches and
fictional incident evidence. `main` is the secure baseline; each `demo/*`
branch deliberately removes one protection so an expected check fails.

Do not report the documented `demo/*` failures as unexpected vulnerabilities.
If you find a different issue that could expose real data, credentials, or
repository access, report it privately through GitHub's private vulnerability
reporting when available. Otherwise, contact the repository owner directly. Do
not include sensitive details in a public issue.

Never replace the test files with employer, customer, production, or
third-party data.
